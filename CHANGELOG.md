# Changelog

All notable changes to this project will be documented in this file.

## [2.1.0] - 2026-10-03

### Added
- Initial public release of the ARK Identifier Resolver WordPress plugin.
- Support for /ark:/xxxxx/name and /ark:/xxxxx/name/qualifier URLs.
- Embedded browser mode and HTTP redirect mode.
- Admin interface for managing ARK mappings.
